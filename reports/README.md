# Reports

This directory contains compact, reviewed reports and aggregate tables. Raw experiment logs, private-data outputs, OOF arrays, and unreviewed generated figures do not belong here.

See the [results and evidence status](../docs/results.md) and [curated-results index](curated_results/README.md). The synthetic benchmark is fully generated by public code. The competition data and historical prediction artifacts are not included; competition results are aggregate findings with explicit validity notes.
