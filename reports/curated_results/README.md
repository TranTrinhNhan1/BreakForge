# Curated results

Result classes stay separate so readers can distinguish reproducible behavior from competition-derived history.

1. **Clean and reproducible:** [`synthetic_benchmark.csv`](../synthetic_benchmark.csv) is generated by public code with a fixed seed. Each row is labeled `SYNTHETIC_ONLY`; configuration, code revision, metrics, and limitations are documented in [results.md](../../docs/results.md).
2. **Official competition runs:** [`official_runs.csv`](official_runs.csv) records scored and unsuccessful provider outcomes, including an import failure. Every row carries an outcome-validity label. These are private-evaluation records, not reproducible benchmarks or rank claims.
3. **Historical research:** [`historical_research.csv`](historical_research.csv) contains selected exact-stream, post-selection, non-nested, partial-fold, code-only, and archived protocol-mixed outcomes. Every row has explicit validation labels, matched-control context where known, and source evidence. Unknown protocol or configuration fields remain unknown.
4. **One-time holdout diagnostics:** [`holdout_diagnostics.csv`](holdout_diagnostics.csv) records four grouped-ID CV-B metrics labeled `CLOUD_PRIVATE; ONE_TIME_EXPOSED_DIAGNOSTIC`, with source digests. The split is no longer treated as a sealed final holdout and must not be used for additional selection.
5. **Source score inventory:** [`experiment_score_inventory.csv`](experiment_score_inventory.csv) lists 111 experiment records normalized from a structured ledger. Each row cites `SRC-041` and carries `CLOUD_PRIVATE;UNKNOWN_PROVENANCE`, plus `PARTIAL_FOLD` where applicable. It flags 80 arithmetic-consistent five-score vectors, 8 vectors with summary mismatches, and 23 partial or ambiguous records. Evaluation protocols were not reconstructed; no row is eligible as a benchmark. See the [inventory notes](../../docs/historical_score_inventory.md).

Competition-derived results are aggregates only. The repository excludes source data, labels, per-series identifiers, predictions, checkpoints, and artifacts that would reproduce or expose the competition dataset. See the [competition data policy](../../docs/competition.md) and [validation guide](../../docs/validation.md).
