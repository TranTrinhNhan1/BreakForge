# Curated results

Result classes stay separate so readers can distinguish reproducible behavior from competition-derived history.

1. **Clean and reproducible:** [`synthetic_benchmark.csv`](../synthetic_benchmark.csv) is generated by public code with a fixed seed. Configuration, code revision, metrics, and limitations are documented in [results.md](../../docs/results.md).
2. **Official competition runs:** [`official_runs.csv`](official_runs.csv) records scored, timed-out, stopped, and protocol-failure outcomes. These are private-evaluation records, not reproducible benchmarks or rank claims.
3. **Historical research:** [`historical_research.csv`](historical_research.csv) contains selected exact-stream, post-selection, non-nested, partial-fold, code-only, and archived protocol-mixed outcomes. Each row identifies its limitations and evidence source. Unknown protocol or configuration fields remain unknown.
4. **One-time holdout diagnostics:** [`holdout_diagnostics.csv`](holdout_diagnostics.csv) records four grouped-ID CV-B metrics and their source digest. The split is no longer treated as a sealed final holdout and must not be used for additional selection.

Competition-derived results are aggregates only. The repository excludes source data, labels, per-series identifiers, predictions, checkpoints, and artifacts that would reproduce or expose the competition dataset. See the [competition data policy](../../docs/competition.md) and [validation guide](../../docs/validation.md).
